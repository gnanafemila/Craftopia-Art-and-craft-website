# Craftopia – Artist Marketplace & Workshop Platform

## About the Project

**Craftopia** is a web-based platform designed for artists and creative individuals. It provides a space where artists can create and manage workshops, sell their handmade products, and upload teaching videos to share their skills and knowledge.

The main objective of Craftopia is to connect artists and learners through creative workshops, products, and educational content.

## Features

- **Artist Registration:** Allows artists to create an account on the platform.
- **Workshop Management:** Enables artists to create and manage their workshops.
- **Product Marketplace:** Allows artists to showcase and sell their creative products.
- **Teaching Videos:** Provides a platform for artists to upload teaching videos and share their knowledge.
- **Creative Learning:** Helps users explore workshops and learn different artistic skills.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Install and open XAMPP.

3. Copy the project folder into the `htdocs` directory.

4. Start Apache and MySQL from the XAMPP Control Panel.

5. If the project uses a database, create the required database in phpMyAdmin and import the project SQL file.

6. Open the application in your browser:

   ```text
   http://localhost/Craftopia/
   ```
